Touch targets

Tab pills (Chapters / Words)Switch tab. Resets scroll, clears selection if switching away.
Word / chapter rowSelect row. Highlights it. Enables Open button. Scroll list by dragging.
Open buttonChapters: close overlay + jump to chapter. Words: show search results for selected word.
X (close button)Close overlay entirely. Returns to reading view.
< (back arrow, results)Return to word list. Selection preserved. Can re-open results or pick another word.
Result row (results)jump_to_occurrence(). Closes overlay, navigates to chapter + page of that hit.
List area (drag)Scroll the list. Scrollbar thumb updates position in sync.
Scrollbar thumb (drag)Drag thumb to scroll list directly. Thumb tracks finger position. List scrolls in sync with thumb.
Scrollbar rail (tap)Tap anywhere on the scrollbar track. Thumb jumps to tap position. List scrolls to matching offset.

Scrollbar spec (paint_scrollbar)

PositionRight edge of list area, inset by SB_TRACK_PAD (10px on device)
TrackFull list height. SB_TRACK_COLOR = 0xD6BA (light gray). SB_TRACK_W = 6px on device.
ThumbSB_THUMB_COLOR = 0x94B2 (medium gray). SB_THUMB_W = 6px. Rounded caps.
Thumb heightvisible_rows / total_rows * list_height. Clamped min = SB_THUMB_W * 2 (12px on device).
Thumb positionscroll / scroll_max * (list_height - thumb_height).
InteractionDrag thumb = direct scroll. Tap rail = thumb jumps, list snaps. Replaces visual-only scrollbar.
VisibilityScrollbar appears only when item_count > visible_rows (~19). Hidden when content fits in one page.
